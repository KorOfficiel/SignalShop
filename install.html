🛒 Installer SignalShop

Suivez ces étapes pour installer votre assistant commercial.

1. Téléchargez le projet

Clonez le dépôt GitHub ou téléchargez le fichier ZIP.

2. Installez les prérequis

Docker Desktop, Git, Python 3.

3. Lancez l'installation

Double-cliquez sur install.bat et suivez les instructions.

4. Ouvrez le dashboard

Allez sur http://localhost:3000 et connectez-vous.
